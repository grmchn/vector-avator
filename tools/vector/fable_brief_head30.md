頭の向きは、30° きざみの**鍵の頭**（正面・30°・60°・90°）の間を、部品の形を点ごとに混ぜる**中割り**でつなぎます。正面の頭（`vector.json`）、斜め 60° の頭（`head60.json`）、真横の頭（`head90.json`）はすでにあります。今回は、その間の**斜め 30° の頭**（頭の輪郭・耳・揺れ物と、目・眉・口・鼻・頬の差分）だけを描きます。体・手・腕は描きません。

## 最初に読むもの

1. `tools/vector/fable_brief_head60.md` の「最初に読むもの」「守ること」「形を優先する」「検査」— 描き方の約束は 60° の頭と同じ。以下、「60°」を「30°」、`head60.json` を `head30.json`、`body60.json`・`ref/body60.png` を `body30.json`・`ref/body30.png` と読み替える。
2. `docs/vector-parts.md` §8.3・§8.5（真横・斜め 60° の頭の形式。30° の頭も同じ形式で、`"view": "head30"`、`"kind": "head"`、`"yaw": -30`）。
3. 正面の頭（`public/characters/{{ID}}/vector/vector.json` の頭の部品）、斜め 60° の頭（`head60.json`）、真横の頭（`head90.json`）— **この 3 枚の間でつながる形**にする。
4. 参照画像（`public/characters/{{ID}}/vector/ref/`）：`body30.png`（1024×1536、**主な参照**。H3 の回転動画の 30° のコマ。この絵と同じ座標・大きさで描く。キャラは自分の右へ約 30° 向いている）、`front.png`・`sheet_face.png`（斜めの顔・目・口・表情の差分）、`sheet_turnaround.png`（斜めの図）、`body60.png`、`turntable.mp4`。H3 の画風は参考にしない。

## 30° の頭で特に守ること

- **30° の向き（視差 0）で見た形**が、参照 `ref/body30.png` の頭と、正面の頭・60° の頭と同じ画風で、そのまま正しく見えることを最優先にする。頭の輪郭、耳の位置と幅、目・鼻・口の位置は、参照を画素で測って合わせる。`skeleton.head_center`・`head_radius` も参照を測って書く。
- `skeleton.head` は `public/characters/{{ID}}/vector/body30.json` の `skeleton.head` と**同じ値**にする。
- 正面の頭（0°）と 60° の頭の**ちょうど間の見え方**になっているかを、3 枚を並べた画像（正面・30°・60°、同じ倍率・同じ支点）で確かめる。頭の大きさ・耳の付け根・目の高さが 3 枚でそろい、目・鼻・口が 0°→30°→60° で一方向へ滑らかに移ること。
- 部品の id・`group`・`variants`・`layer`・`clipTo`、**各部品の shape の名前・数・順**は、正面の頭と 60° の頭と同じにする（60° の頭にある白目の縁 `eye_<側>_ring` も描く）。1 つの shape は閉じた輪 1 つ（`M … Z` が 1 回）。新しい部品を足さない。
- 奥の目・眉・頬（`_R`）も描く。30° では奥の目は正面よりやや細く、輪郭の内側に収まる。
- `parallax`・`headTurn` は正面の頭と同じ値（`vector.json`。なければ既定値）にする。
- `order` は、正面の頭の順を基本に、体の部品どうしの前後は `body30.json` の `order`（なければ正面の `vector.json` の体の部品の順）と同じにする。耳の前後は参照に合わせる（60° の頭では手前の耳を頭の手前に置いている）。
- 頭の揺れ物（耳）のチェーンは、同じ id で 30° の位置に書く（`root`・`tip`。硬さなどは正面の値）。

## 検査（納品前に必ず行う）

1. `head30.json` の部品（既定の表情）を描画順に重ねた画像（`preview.png`）を作り、`ref/body30.png` の頭と並べた画像・半透明で重ねた画像で、形・色・位置を目で見て確かめる。
2. 正面・30°・60°・90° の頭を、同じ倍率・同じ支点で並べた画像（`keys.png`）を作り、つながりを確かめる。
3. 目の差分・口の 9 種・眉の差分・表情 4 種の一覧画像、手前の部品を隠した画像、`skeleton` の目印の画像を作って確かめる。
4. `.venv/bin/python tools/vector/check_parts.py {{ID}} --view head30` を実行し、エラー 0・警告 0 にする（30° の体に乗せた状態で検査される）。`--view` が `head30` に対応していない場合は、そのことを報告し、`--view head60 --body body30.json` などで代わりに確かめられる範囲を確かめる。
