## 守ること

- 部品は意味の単位で**ゼロから描く**。参照画像の画素の切り抜き、自動トレース、色分類・可視輪郭の当てはめで形を決めない。画像処理は、色の抽出、寸法・座標の測定、拡大、重ねての比較に限る。
- **塗りだけで描く**（`stroke: null`、`width: 0`）。参照画像の灰色の境界線は描かない。目・口・眉の線は、正面と同じく細い塗りの形で描く。
- 手前の顔の側はキャラの**左（`_L`）**。60° では**奥の目・眉・頬（`_R`）も描く**（顔の輪郭の縁に細く見える。視差で 30° の向きまで回したときに広がって見えるので、隠れる部分も補完して描く）。耳・ツインテールなど左右両方が見えるものは、奥（`_R`）も描く。
- 部品の id・`layer`・`group`・`variants`・`clipTo` は正面と同じにする。正面にある目の差分（開・半・閉・笑顔など）、眉の差分、口の 9 種（`closed`・`a`・`i`・`u`・`e`・`o`・`smile`・`surprise`・`trouble`）を**すべて斜め 60° の顔で**描く。正面にない部品を足す場合は、正面の命名規則に合わせる。
- 頭の揺れ物（耳・ツインテール・前髪の房など、正面の `chains` で `bone` が `head` のもの）は、同じ id のチェーンを斜め 60° の位置で書く（`root`・`tip`・硬さなどは正面の値を基準にする）。
- `skeleton.head`（首の上端・頭の回転の支点）、`skeleton.head_center`（頭の球の中心）、`skeleton.head_radius` を、参照画像を**画素を走査して測って**書く。`head` は `public/characters/{{ID}}/vector/body60.json` の `skeleton.head`（首の上端の中央、頭の回転の支点）と**同じ値**にする（`docs/vector-parts.md` §8.5。斜め 60° の頭はこの点で 60° の体に重ねて乗せる）。
- `order` に、体の部品（正面の `vector.json` の体の部品と同じ id）も含めた全部品の描画順を書く。**体の部品どうしの前後は、`body60.json` の `order`（なければ正面の `vector.json` の体の部品の順）と同じにする**（斜めの頭と組むときは `head60.json` の `order` が全体を上書きするため）。手・袖は書かなくてよい。
- **隠れる部分も補完する**：髪の内側、顔の輪郭の裏（首とのつなぎ目）、耳・ツインテールの付け根。斜め 60° の頭を視差で ±30° 回したとき（30° の向き〜90° の向き）（顔の部品が横へずれ、髪が少し縮む）にも穴が出ないこと。
- 1 shape は 80 区間以下を目安にする。

## 形を優先する

斜め 60° の頭は、頭の向きの**中割りの鍵の絵**として使う。そのため、**60° の向き（視差 0）で見た形が、参照 `ref/body60.png` の頭（H3 の 60° のコマ）と、正面の頭・真横の頭と同じ画風で、そのまま正しく見えること**を最優先にする。

- 頭の輪郭（後頭部の丸み、あごの線）、耳の位置と幅、目・鼻・口の位置は、参照の 60° のコマを画素で測って合わせる。`skeleton.head_center` も参照の頭の球の中心を測って書く（つなぎ目のために動かさない）。
**同じことをしない。** 中割りでは切り替えの一瞬がなくなるので、つなぎ目の数値は必須ではない。
- `parallax`・`headTurn` は、正面の頭と同じ値（`vector.json` の値。なければ既定値）を出発点にし、極端な値（0、負、1.5 など）にしない。中割りの間では、残りの小さな角度（±2° 程度）と上下の向きにしか使わない。
- **中割りに使えるように、部品のつくりをそろえる。** 部品の id・`group`・`variants`・`layer`・`clipTo` は正面の頭と真横の頭と同じにし、**各部品の shape の名前・数・順は、正面の頭（なければ真横の頭）と同じ**にする。1 つの shape は**閉じた輪 1 つ**（`M … Z` が 1 回）で描く。正面にも真横にもない部品を新しく足さない（例外は §8.3 の白目の縁 `eye_<側>_ring`）。
- 輪の形が鍵の間で大きく変わらないようにする（同じ部品の輪は、隣の角度の絵でも同じ部分が同じ側に来るように描く。たとえば耳の内側の帯を、ある角度では左の縁、次の角度では右の縁に置かない）。
- つなぎ目の計測（`tools/vector/head_seam.mjs`・`head_seam.py`、下の手順）は**参考として**行い、数値を報告する。形を崩してまで合わせない。
  ```
  node tools/vector/head_seam.mjs var/vector/{{ID}}/{{WORK}}/seam {{ID}} 30 0,60
  node tools/vector/head_seam.mjs var/vector/{{ID}}/{{WORK}}/seam {{ID}} 75 60,90
  .venv/bin/python tools/vector/head_seam.py var/vector/{{ID}}/{{WORK}}/seam {{ID}}:30:0:60 {{ID}}:75:60:90
  ```
  （開発サーバー http://127.0.0.1:5280/ が必要。非対話シェルでは先に `export PATH=$HOME/.nvm/versions/node/v22.23.0/bin:$PATH`）
- 耳・ツインテールの付け根の間隔と幅は、レンダラーが向きに合わせて自動で変える（§8.5）。耳は 60° から見た本来の位置・幅で描けばよい。

## 検査（納品前に必ず行う）

1. 自分で、`head60.json` の部品（既定の表情：目は開、口は閉）を描画順に重ねた画像を作り（`var/vector/{{ID}}/{{WORK}}/preview.png`）、`ref/body60.png` の頭と並べた比較画像・半透明で重ねた比較画像を作って、形・色・位置が合っているかを**目で見て**確かめる。
2. 目の差分・口の 9 種・眉の差分・表情 4 種を並べた一覧画像を作り、斜めの顔として読めるか、位置がずれていないかを確かめる。
3. 手前の部品を隠した画像を作り、穴・切り口がないかを確かめる。
4. `skeleton` の目印を点で描いた画像を作り、位置が絵と合っているかを確かめる。
5. `.venv/bin/python tools/vector/check_parts.py {{ID}} --view head60` を実行し、エラー 0・警告 0 にする（60° の体 `body60.json` に乗せた状態で検査される。`--body body30.json` で 30° の体にも乗せて見る）。
6. 「形を優先する」のつなぎ目の計測を参考として 30° と 75° で行い、数値と比較画像を報告に付ける（目安に入れるために形を崩さない）。
7. ビューアで `?char={{ID}}&renderer=V&motion=turn90_slow&t=2`（30°）〜`t=5`（75°）などを撮って、視差で回した途中の形も確かめる（撮影は `node tools/capture/viewer_shots.mjs <出力フォルダ> <名前>="<クエリ>" ...`）。レンダラーは `head60.json` があれば自動で使う。
