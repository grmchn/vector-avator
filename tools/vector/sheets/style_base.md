【目的・基本スタイル】

大きな頭と小さな体を持つ、独創的で愛嬌のある動物またはクリーチャーを描く。

少数の大きく滑らかな形と、整理されたフラットな色面を中心とする、ミニマルな2Dイラスト。かわいらしさと、生き物としての構造的な説得力を両立させる。

塗りはフラットだが、頭・胴・手足は厚みと丸みを持つ立体として捉える。手描き感はごく控えめな隠し味にとどめる。

【頭身・比率：最優先】

2〜2.5頭身。基本は約2.3頭身とし、2.5頭身を超えない。

耳・角・帽子・髪の膨らみを除いた頭部本体の高さを基準とする。頭部本体は、直立した場合の全身の高さの約40〜45％。顎から足裏までを頭の約1.2〜1.5個分に収める。

頭は大きく、首は短く、胴と手足はコンパクトにする。衣装の再現やポーズの誇張のために、胴や脚を長くしない。

【造形・体のシルエット】

少数の特徴的な形で、そのキャラクターの個性を表現する。耳・尾・手足などは、動きや役割を感じられる自然な構造と接続にする。

髪・衣装・装飾を除く体本体は、滑らかな塊として整理する。輪郭に細かな凹凸を増やさない。

顔は額から頬、顎までを大きな連続した曲線でつなぐ。頬の張り出し、顎の段差、口元の膨らみを細かく重ねない。鼻先やくちばしなど、種を特徴づける形は必要最小限の大きな形として残す。

腕と脚は、緩やかに太さが変化する簡潔な形にする。肘・膝・手首・足首に、こぶ状の膨らみ、強いくびれ、細かな段差をつくらない。関節の曲がりは、方向・重なり・短縮で表現する。

手は丸いミトン状の塊を基本とし、動作に必要な指だけを短く分ける。足も丸い塊としてまとめ、細かな骨格や指の起伏を省略する。

意味のない突起、複雑なうねり、過度な尖り、ランダムな模様は避ける。模様は部位や形の流れに沿って配置する。

【顔・目・視線】

目には白目と色のある虹彩を描く。必要に応じて、虹彩の内側に独立した濃色の瞳孔を加える。

目の外形は丸・楕円、または柔らかな曲線を含む三角・菱形。鋭く尖らせすぎず、両目を離しすぎない。

目や顔パーツは頭の曲面に沿って配置する。斜め向きでは、遠近に応じて奥側の目の横幅や見える範囲を変化させる。

正面を見るときは、左右の虹彩・瞳孔をそれぞれ鼻側へ寄せない。各眼球の正面方向に自然に配置し、鼻側の白目が両目とも極端に狭くなる寄り目を避ける。目の外形を寄せて補正しない。

横を見るときは、両目の虹彩・瞳孔を同じ視線方向へ連動させる。顔の向きと視線方向を区別して扱う。

白目・虹彩・瞳孔は、それぞれ均一な単色の面として描く。虹彩・瞳孔の内部に、ハイライト、白い点、明るい斑点、反射、光沢、光の帯、きらめき、グラデーションを一切入れない。目の内部には塗りムラやノイズも加えない。

白目は虹彩の外側の面として表現し、虹彩内部の白い抜きで代用しない。

眉・まぶた・まつ毛は表情に必要な量に絞る。半目は選択肢の一つとし、標準表情には固定しない。

口は簡潔で表情の伝わる形にする。ω型の猫口を標準にせず、短い曲線、小さな開口、その生き物に合った構造を優先する。

【色・陰影・立体感】

少数の整理された色を使い、大きな色面で塗り分ける。色調をパステルや低彩度に固定せず、キャラクターに合った基本色を用いる。

各部は基本色を中心とし、必要な陰影も広く弱い1段階程度にとどめる。細かな陰影、多数の中間色、滑らかな明暗グラデーションで描き込まない。

立体感は、シルエットの曲率、重なり、遠近、短縮、色面の回り込みで表現する。強い照明効果、過度な光沢、3Dレンダーのような質感は避ける。

【境界線・手描き感】

形は隣接する色面の差を中心に見せる。必要な境界線や内部線には、その部位の塗り色より少し濃い同系色を使う。

背景や隣接部と色が近く、形が埋もれる部分には、細い境界線を輪郭の内側に沿って加える。白には明るい灰色、淡い青には少し濃い青など、塗り色と調和する色を選ぶ。

線を省くことよりも、必要な境界が読めることを優先する。ただし全身を太い黒線で一律に囲まず、外側の縁取りや発光で補わない。

色面の内部には、ごく薄い塗りムラを加えてよい。エッジには微細な揺れ・かすれ・欠けを控えめに残してよい。通常の表示サイズでは、フラットな色面と明快な形が先に見える強さにする。

強い粒状ノイズ、目立つ筆跡、厚塗り、汚し、毛並みの描き込みは避ける。

【髪・衣装・装飾】

髪や毛は数個の大きく滑らかな塊にまとめ、細かな毛束や後れ毛を増やさない。

衣装はシルエット、襟、袖、裾、主要な配色を優先する。柄や装飾は少数の大きな形に置き換える。

細かなレース、刺繍、縫い目、金具、複雑な模様は省略する。衣装は小さな体の比率に合わせて再設計する。

【ポーズ・動勢】

小さな体でも、伸びやかで明快なジェスチャーを持たせる。

頭・胸・骨盤の傾き、肩と腰の逆方向の傾斜、体のひねり、支持脚と遊脚の差を活かす。重心と動勢がシルエットから読めるようにする。

腕の開き、手の到達方向、脚の踏み出しを縮こまらせない。胴と腕、左右の脚の間に適切な空間を確保する。

動きは角度・配置・重なり・短縮で誇張する。手足や胴を長くしたり、関節の輪郭を複雑にしたりして表現しない。

【競合時の優先順位】

1. 2.5頭身以下の、大きな頭と小さな体。
2. 正面視で寄り目にしないこと、目にハイライトを入れないこと。
3. 少数の滑らかな形とフラットな色面による簡潔さ。
4. 必要な境界の読みやすさ。
5. 構造に説得力のある独創性、立体感、伸びやかなポーズ。
6. ごく控えめな手描き感。
7. 衣装や装飾の細部。

細部が上位の条件と競合する場合は、細部を省略する。

【画像からの変換】

入力画像から、対象の代表的な配色、髪型のシルエット、衣装の主要な特徴、持ち物、表情、顔の向き、視線方向、ポーズの動勢を読み取る。

識別に必要な特徴を残しながら、共通スタイルの頭身・造形・描画方法に再構成する。元画像の頭身、写実的な骨格、細かな凹凸、描き込み量は引き継がない。

人物は、特に指定がなければ動物またはクリーチャーとして再解釈する。耳だけを追加するのではなく、頭部・口元・手足まで一貫した生き物として設計する。既存の動物・クリーチャーは、その種類と中核的な特徴を維持する。

目は共通スタイルに従って描き直す。元画像にハイライト、反射、虹彩のグラデーションがあっても除去する。元画像の目の描き方より、ハイライトなし・正面視で寄り目にしない条件を優先する。

元画像の重心、体の傾き、ひねり、腕の開き、脚の踏み出しを保ち、特徴的な動勢を適度に誇張する。頭身を縮めてもポーズを萎縮させない。

体の輪郭は滑らかな少数の塊へ整理し、顔や関節の細かな膨らみ・くびれ・段差を省略する。

元画像の淡い基本色は維持する。背景と同化する部分には、内側の色を少し濃くした細い境界線を加える。

変換対象画像とスタイル参考画像が別にある場合は、参照元を区別する。スタイル参考画像のキャラクター固有の色・髪型・装飾を移植しない。

【キャラクターシート・資料として描く場合の追加条件】

この画像は、2D アニメーション用の部品を描き起こすための資料である。見やすさと一貫性を、絵としての演出より優先する。

背景は無地の明るい単色（ごく薄い青灰色）とし、影・床・模様・装飾・枠線を描かない。

白いキャラクターでも形が読めるよう、各部の境界には、その部位の塗り色より少し濃い同系色の細い線を引く。黒い太線で全身を囲まない。

同じ画像に描く全ての図で、頭身、頭の大きさ、色、形、線の太さを揃える。同じキャラクターであることが一目で分かるようにする。

ポーズの指定がある図では、【ポーズ・動勢】の項よりも、そのポーズの指定を優先する。指定のない誇張・ひねり・傾きを加えない。

腕を体から離して描く図では、脇と胴の間に背景が見える隙間を作り、腕の下の胴の形が見えるようにする。

目にはハイライト・白い点・反射を一切入れない。正面の図では寄り目にしない。

キャラクターごとの補足がある場合は、補足を最優先する。キャラクターの識別に必要な特徴を、共通スタイルのために削ったり変えたりしない。
