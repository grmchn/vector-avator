【この画像で描くもの：キャラクターシート 2 枚目（顔・目・口・表情）】

横長のキャラクターシートを 1 枚描く。全て同じキャラクターの、肩から上の頭部の図である。全ての頭部は同じ大きさ・同じ画風で描き、3 行のグリッドに等間隔で並べる。耳や髪が長い場合も、頭部どうしが重ならないように間隔を取る。

1 行目（5 図）：左から
1. 正面の顔（通常）
2. 斜め約 45 度の顔（画面の左側へ顔を回した 3/4 ビュー。通常の表情）
3. 正面の顔：目を開いた状態（通常）
4. 正面の顔：半目（上まぶたが黒目の上半分を隠す。黒目の形は潰さない）
5. 正面の顔：目を閉じた状態（ゆるやかな下向きの弧）

2 行目（6 図）：正面の顔で、口の形だけを変える。目は開いた通常の目のまま。左から
1. 閉じた口
2. 「あ」（縦にも横にも大きく開く）
3. 「い」（横に広く、縦は狭い）
4. 「う」（小さくすぼめた丸）
5. 「え」（横長で中くらいに開く）
6. 「お」（縦長の丸）

3 行目（4 図）：正面の顔で、表情を変える。左から
1. 通常
2. 笑顔（目を細め、口を開けて笑う）
3. 驚き（目を丸く見開き、眉を上げ、口を小さく丸く開ける）
4. 困り（眉尻を下げ、口を小さく波打たせる）

各図の下に、小さな日本語のラベルを付ける：正面、斜め、開き、半目、閉じ、閉、あ、い、う、え、お、通常、笑顔、驚き、困り。ラベル以外の文字、タイトル、枠線、矢印は描かない。眉のないキャラクターでも、表情は目・まぶた・口の形で区別する。
