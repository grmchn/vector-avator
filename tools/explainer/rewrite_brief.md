## 2. 守ること

1. **要旨を変えない。** 各行の「要旨」の内容をすべて言う。要旨にないことを足さない（あいさつ・相づち程度の言葉は足してよい）。
2. **行を足したり消したりしない。** 行の数・順・ID は内容層と同じにする。
3. **必ず言う語は言い換えない。** 「必ず言う語」はそのまま字幕に入れる（ひらがな・漢字の表記ゆれも避ける）。
4. **長さの目安を守る。** 各行の「長さの目安」から大きく外さない（目安：かなで 1 秒あたり約 {{mora_rate}} モーラ。目安の 0.7〜1.3 倍に収める）。
5. **キャラらしさは言い回しで出す。** 一人称・語尾・呼びかけ・言葉の選び方で出す。一人称は「{{first_person}}」以外を使わない。
6. **強調の語には印を付け直す。** 「強調する語」がある行は、`anchors` に、その語を台本のどこで言うか（字幕の部分文字列 `ja` と、かなの部分文字列 `kana`）を書く。
7. **キャラ名を名乗る行**（備考に「キャラ名を名乗る」）では、字幕は「{{char_name}}」、`ja_tts`・`ja_kana` はその読み「{{name_reading}}」で名乗る。
8. **字幕だけの記号は読ませない。** 語尾の「w」や絵文字など、声に出さない記号は字幕（`ja`）にだけ書き、`ja_tts`・`ja_kana` には入れない。

## 3. 各行に書くもの

| 項目 | 内容 |
|---|---|
| `id` | 内容層の行 ID |
| `ja` | 字幕。読みやすい表記（漢字・カタカナ・英字可） |
| `ja_tts` | TTS に渡す文。英字の略語・数字・読み間違えやすい語は読みどおりに書く（例：`AGI` → `エージーアイ`、`2045 年` → `にせんよんじゅうご年`、`Fable 5.2` → `フェイブル ごーてんに`）。句読点で間を作る |
| `ja_kana` | ひらがなの読み。ひらがな・長音「ー」・空白・句読点だけ（カタカナ・漢字・英字・数字は使わない）。口パクに使う |
| `anchors` | 強調する語ごとに `{"ja": 字幕の部分文字列, "kana": ja_kana の部分文字列}`（強調する語がある行だけ） |

## 4. 出力

次の形の JSON を `{{out_path}}` に書いてください（UTF-8、インデント 1）。

```json
{
 "format": "explainer-script",
 "version": 1,
 "content": "{{content_id}}",
 "char": "{{char}}",
 "note": "{{char_label}}の口調で書き直したもの",
 "lines": [
  {"id": "L01", "ja": "…", "ja_tts": "…", "ja_kana": "…"},
  {"id": "L03", "ja": "…", "ja_tts": "…", "ja_kana": "…", "anchors": {"語": {"ja": "…", "kana": "…"}}}
 ]
}
```

書いたら、次の検査を実行し、エラーが 0 件になるまで直してください。警告（長さ・一人称・必ず言う語）も、できるだけ 0 件にしてください。

```bash
.venv/bin/python tools/explainer/make_script.py check {{content_dir}} {{char}}
```
