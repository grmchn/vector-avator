# 目視で完了を判断する

## 1. 元絵とニュートラル合成を並べる

同じ大きさで並べ、次をこの順で見る。

1. 全身のシルエット、頭身、髪の長さ、手足の位置。
2. 顔の目幅・目の高さ・顎・口・眉・ハイライト。「同じ人物に見えるか」。
3. 主な色面と線の太さ。輪郭がガタつく、細かい島が散る、白い縁が出るなら抽出の残骸を疑う。
4. 重なり。前髪が目を不自然に覆う、袖が手を隠す、内部模様が外輪郭を消すなど。

小さなアイコンサイズと100〜200%の表示の両方で確認する。輪郭が滑らかでも別人に見える場合は完成ではない。絵柄を単純化する必要がある場合は、その範囲を説明する。

## 2. 補完された形だけを見る

全部品一覧と `reveal` を開く。「部品名が顔」ではなく、実際に額・こめかみまである顔かを確認する。肩・上腿・髪の根元が直線で途切れていたら修正。隠れている区間がカクカクした継ぎ足しになっていたら曲率を直す。

不自然に大きなベタ面を置いて全部の穴を塞ぐだけにしない。その部品単体として納得できる輪郭・幅があるかを見る。

## 3. 想定範囲で動かす

部品の支点を使い、左右両方向の最大想定角度・移動量を試す。特に根元、肩、首、腰、袖口、脚の付け根を見る。もともと背景が見えるべき場所と、身体が抜けた透明な穴を区別する。

前髪を動かすと露出する額、ネクタイを動かすと出る胸元、スカートをずらすと出る腿を確認する。クリッピングや他のパーツで問題を隠さず、原画を補完する。

これは平面内の原画テストで、衝突ソルバーではない。「どの角度でも破綻しない」といった説明をしない。

## 4. 表情差分

閉じ目表示で白目やまつ毛が残っていないか。口を開けたとき閉じた笑顔線が重ならないか。片目だけの差し替えも必要なら確認する。

## 5. ビューアでの見え方

確認画像（`check_parts.py`）には、自動輪郭線と生成した腕が入らない。最後はビューアで見る。

- 白いキャラ・同系色の部品の境目に、参照にない線が出ていないか（出る場合は `seamlessWith`・`outline: false`）。
- 首振り ±30° で、目・頬が顔の輪郭の外へ出ないか。耳・髪の付け根が頭から離れないか。髪の縁に二重の線が出ないか。
- 腕の太さ・色の帯・影が絵と合っているか。腕を胸の前に出したとき、胴の前に描かれるか。
- 手の形 4 種が、手首でずれずにつながるか。
- 揺れ物（耳・髪・しっぽ）が、付け根で頭・体から離れずに揺れるか。

## 作業メモに残す判定

`QA名 / 確認した画像 / 見つけた問題 / 修正または未解決 / 再確認結果` を簡単に記録する。自動レポートの `visual_review_required:true` を、実際に見ないまま false に変える運用にしない。

完了の基準は「生成コマンドが成功した」ではなく、上の比較を行い、修正できる破綻を直して、ビューアで動かしても破綻がないこと。未確認・未解決を隠さない。
