# キャラの補足と、Fable へのキャラごとの注意の書き方

キャラごとに書くものは 3 つです。どれも「共通の手順では決まらない、そのキャラだけの事情」を書きます。

| ファイル | 読む相手 | 書くこと |
|---|---|---|
| `tools/vector/sheets/characters/<id>.md` | Codex imagegen（画風の変換・シート） | 画風を変えても残すべき特徴。共通の画風を打ち消す指示 |
| `tools/vector/sheets/characters/<id>.json` | `make.py` | 原画のパスと、その画像の役割 |
| `var/vector/<id>/fable/notes.md` | Fable 5.2（部品分け） | 部品の割り当て、揺れ物、線を出さない組、腕の前後など |

## 1. `<id>.md`（キャラの補足）

- 1 行目に、どんなキャラかを 1〜2 文で書く。
- 「残すべき特徴（共通スタイルより優先する）」として、識別に必要な特徴を箇条書きにする：シルエット（耳・髪・しっぽの形）、色（`#RRGGBB` のおおよその値）、目の形と色、顔の部品の配置、衣装の主な特徴、頭身。
- 共通の画風（`style_base.md`）はキャラを「動物・生き物」として描かせるので、そのままではキャラが変わる点を、ここで打ち消す。例：毛のないキャラに「毛の房・毛羽立ちを描かない、つるりとした体」、人物でないキャラに「動物として再解釈する は適用しない」。
- 元画像の描き方（黒い太い輪郭線など）を変える指示も、ここに書く。

仮うさぎの例（`tools/vector/sheets/characters/usagi.md` の抜粋）：

```text
【キャラクターごとの補足：仮うさぎ（キャラ ID: usagi）】

添付の元画像とキャラクターシートの、白いうさぎのキャラクターを描く。シンプルで素朴なマスコットであることが、このキャラクターの個性である。

残すべき特徴（共通スタイルより優先する）：
- 全身が真っ白で、毛の房・毛羽立ち・ふわふわの毛の描き込みがない、つるりとした滑らかな体。共通スタイルの「毛の量感」は適用しない。
- 頭頂から真上に伸びる、とても長い 2 本の耳。耳は頭とほぼ同じ高さがあり、先が丸く、根元が細い。耳の内側は明るい水色（#5FCDF8 前後）の細長い楕円。
- 小さな横長の楕円の赤い鼻（朱色、#D24A32 前後）。
...
```

## 2. `<id>.json`（原画）

```json
{
  "id": "usagi",
  "name": "仮うさぎ",
  "notes": "characters/usagi.md",
  "refs": { "original": ["inputs/kariusagi/kariusagi4.png", "inputs/kariusagi/仮うさぎ_キャラクターシート.png"] },
  "roles": {
    "inputs/kariusagi/kariusagi4.png": "the original character design (front, ...)",
    "inputs/kariusagi/仮うさぎ_キャラクターシート.png": "the original character sheet (front / side / back and expressions)"
  }
}
```

- `refs.original` のパスはリポジトリのルートから。原画が 1 枚だけなら 1 つでよい。
- `roles` は英語で、その画像を何に使うか（デザインの正、色の参考、表情の参考など）を書く。原画の口が開いている、体をひねっているなど、そのまま写してほしくない点もここに書く（例：`do not copy the pose; the target is the front A-pose`）。

## 3. `notes.md`（Fable へのキャラごとの注意）

`fable-brief.md` の `{{NOTES}}` に差し込む。書くこと：

- キャラの性格づけ（「単純さが個性」「髪の塊は大きく」など）。
- **部品の割り当て**：どの塊を何という部品にするか（前髪・横髪・後ろ髪の分け方、内耳を同じ部品の別 shape にする、など）。髪のないキャラは `hair_*` を作らないと明記する。
- **揺れ物**：耳・ツインテール・しっぽ・リボンのうち、どれをチェーンにするか、節の数。
- **線の扱い**：白い部品どうしの境目で線を出したくない組（`seamlessWith`）。顔パーツには自動輪郭線が付かないので、白い顔に白い白目を置くキャラは、白目の縁の輪を shape として描く。
- **腕**：腕を胴の手前・裏のどちらに描くか（`arms.attach`）。袖の有無。手の形（ミトン状、指の数）。
- そのキャラで分かりにくい点（左右非対称の部品、参照画像どうしの食い違いがあればどれを正とするか）。

仮うさぎの例：

```text
- 全身が白い、毛の房のないつるりとしたマスコットです。形は少数の大きな塊（頭、耳 2 本、胴、脚 2 本、しっぽ）で、細かな凹凸を足さないでください。キャラクター性は「単純さ」です。
- 髪はありません。`hair_*` の部品は作りません。
- 耳：`ear_L`・`ear_R`。水色の内耳は同じ部品の別 shape。付け根は頭の中まで伸ばし、頭（`head`）の奥に描きます。揺れ物チェーン（`bone: "head"`、`layer: "ear"`）にします。耳は長いので節は 4 程度。
- 目：大きな縦長の白目、水色の虹彩、縦長の黒い瞳孔。白い顔に白い白目なので、白目の縁の灰色の輪を、白目の部品の奥の shape として描いてください（顔パーツには自動輪郭線が付きません）。まつ毛はありません。半目・閉じ・笑顔の目は `sheet_face.png` に合わせます。
- 眉：目の上の小さな弧の眉 `brow_L/R_normal`。笑顔・驚き・困りの眉もシートから作ります。
- 鼻は小さな赤い楕円、口は鼻のすぐ下の短い弧です。開いた口（あ・い・う・え・お、笑顔、驚き）はピンクの口の中を shape にします。口の線も塗りの細い形にします。
- 腕は短い棒状です。`arms` の太さは `front.png` を測ってください。手はミトン状の丸い手で、指は小さな丸い突起程度（シート下段の 4 種）。
- しっぽ：小さな丸い白いしっぽ `tail`（正面図で画面の右・キャラの左の後ろ）。揺れ物チェーン（`bone: "hips"`、節 2）にします。
- 胴と脚：脚の間の切れ込み、脚の付け根は胴の裏まで補完します。腕は胴の手前に下がるので、`arms.attach` には胴の直後に描かれる部品の id（例：`neck`）を指定します（腕はその部品の直前＝胴の手前に描かれます）。
```
