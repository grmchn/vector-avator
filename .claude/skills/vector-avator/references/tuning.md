# ビューアでの確認と調整

ビューア（`npm run dev` → `http://localhost:5280/`）の URL のパラメーターで見え方を変え、よい値が見つかったら `vector.json` に書き込みます。

## 1. 見るためのパラメーター

| パラメーター | 内容 |
|---|---|
| `char=<id>` | キャラ |
| `motion=<name>` | モーション（`data/motions/` の `name`。`idle`・`explain`・`point`・`spread`・`think`・`nod_surprise`・`talk_demo` など） |
| `t=<秒>` | 時計を止めてその時刻を表示（撮影用） |
| `framing=face` | 顔の拡大 |
| `yaw=<度>`・`pitch=<度>`・`roll=<度>` | 顔の向き（左右は ±30° まで） |
| `eye=open\|half\|closed`、`mouth=sil\|a\|i\|u\|e\|o`、`expr=neutral\|smile\|surprised\|troubled` | 目・口・表情 |
| `blink=0` | 自動まばたきを止める |
| `say=<かな>` | テキストの口パク |
| `bg=<RRGGBB>` | 背景色 |
| `debug=1` | 骨格を重ねて表示 |

## 2. 線

| パラメーター | 既定 | 内容 |
|---|---|---|
| `vOutline=0` | 1 | 自動輪郭線を消す |
| `vOuter=1` | 0 | 外側の輪郭線を引く（`vOuterColor=<RRGGBB>` で色） |
| `vLine=<px>` | 3.2 | 線の太さ |
| `vDark=<0〜1>` | 0.2 | 線の暗さ（部品の色をどれだけ暗くするか） |
| `vThr=<ΔE>` | 16 | 「近い色」とみなす色差。大きいほど線が出る組が増える |
| `vHand=0〜4` | 3 | 手描き風の線：なし・弱・中・強・手描き＋（強＋ボイル 8fps＋大きな揺れ 2px＋クレヨン） |
| `vBoil=<fps>`・`vBoilWob=<px>`・`vTex=pencil\|crayon` | — | 線の描き直し（ボイル）、大きな揺れ、線の質感 |

線を出したくない組は、`vector.json` の部品に `seamlessWith`（相手の部品 id。生成した腕は `arm_L`・`arm_R`）か `outline: false` を書きます。線を消す目的で `color` を塗りにない色にしないでください。

## 3. 首振り（`parallax`・`headTurn`）

`framing=face&blink=0&vBreath=0` を付けて、`yaw=-30,-15,0,15,30` と `pitch=±15` を撮って比べます。

- `vPar=feature:0.8,head:0.6` … 層ごとの動きの量を試す（→ `vector.json` の `parallax`）
- `vTurn=radius:1.3,irisRoll:0.14` … 調整値を試す（→ `headTurn`）
- `vMaxYaw=<度>` … 首振りの上限（既定 30）

各値の意味は `parts-spec.md` §3.5 にあります。見る点：±30° で、(1) 目・頬が顔の輪郭や横髪の外へ出ない、(2) 髪の縁に二重の輪郭線が出ない、(3) 耳・ツインテールの付け根が頭から離れない、(4) 半目・閉じ目・口の差分でもずれない。

## 4. 動き

| パラメーター | 既定 | 内容 |
|---|---|---|
| `vPhys=0` | 1 | 揺れ物を止める |
| `vPhysGain=<倍率>` | 1 | 揺れ物の反応の強さ |
| `vAccMax=<px/s²>` | 60000 | 揺れ物が受ける根元の加速度の上限。速いダンスで耳・髪が跳ね上がるときに下げる（例：8000） |
| `vLag=0` | 1 | 手の遅れ（腕に少し遅れてついてきて、止まるときに行き過ぎて戻る）を止める |
| `vBreath=<px>`・`vBreathT=<秒>` | 5・3.6 | 呼吸（胸の上下）の量と周期。0 で止める |
| `vWag=<rad>` | 0.07 | 待機中のしっぽの揺れ |
| `vPlant=1` | 0 | 足裏を止めたまま、脚を腰へ向けてせん断する（腰を左右に振る動きで足が浮かない） |
| `vPad=<割合>` | — | 撮影の枠の余白（体の高さに対する割合）。跳ねる・耳が大きく振れる動きで切れないように |

揺れ物の硬さは、`vector.json` の `chains[]` の `stiffness`・`damping`・`gravity`（0〜1）で決めます。耳・ツインテールは柔らかく揺れるのが魅力なので、`stiffness` 0.5〜0.75、`damping` 0.3〜0.4（行き過ぎて戻る）が目安です。

## 5. モーションの作り方

モーションは `data/motions/*.json` のキーフレームです（形式は既存のファイルを参照）。骨の名前は VRM 1.0 の人型の骨名（`src/core/skeleton.ts`）で、回転はオイラー角（度）で書けます。顔（向き・目・口・表情）もキーに書けます。キーに `squash`（縦の倍率）を書くと、足元を支点に体が伸び縮みします。
