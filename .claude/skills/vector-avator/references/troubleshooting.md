# よくある問題と対処

これまでのキャラで見つけた問題と対処です。新しいキャラで同じ症状が出たら、まずここを見てください。

| 記号 | 問題 | 対処 |
|---|---|---|
| V1 | imagegen の出力の大きさが 1024×1536 と 1086×1448 で混ざる | `adopt` で正面の立ち姿を 1024×1536 にそろえる（背景の余白だけを切る。切れない場合は余白を足す） |
| V2 | H3 の回転は等速ではない（キャラによって、1 秒で約 15°〜30°） | `angle_<度>.png` の角度は目安。角度ごとの比較では、目の位置などからコマを選び直す |
| V3 | 共通の画風は「動物・生き物」としての描き方を求めるため、毛のないつるりとしたキャラ（仮うさぎ）が、毛の房のある別キャラに描かれることがある | キャラの補足に「毛の房・毛羽立ちを描かない、つるりとした体」のように、残す特徴として具体的に書く。共通の画風プロンプトは変えない |
| V4 | Codex の画像生成には使用量の上限がある | 1 キャラの生成は正面 1〜2 回＋シート 2 回で足りた。比較用の追加生成は後回しにできるよう、採用に必要な分を先に作る |
| V5 | 白い部品が重なる所に参照にない線が出る（耳と頭、胴と脚、手首） | `seamlessWith`・`outline: false`・`arms.*.seamlessHand` で線を出さない組を指定する。`color` を偽の色にして判定から外さない |
| V6 | 腕の色の帯の境目に隙間、帯の上で影の色が合わない、紺の腕と紺のスカートの間に線が出ない | レンダラーで、帯の境目の補間・帯ごとの影・帯ごとの線の判定を行う |
| V7 | 顔パーツには自動輪郭線が付かないため、白い顔の白い白目が見えない | 白目の縁などの線は、顔パーツの shape として描く |
| V8 | 耳がまっすぐ立つキャラは、うなずき・跳ねでばねがほとんど動かない | 揺れ物の駆動に、頭の左右の回転速度（横の遅れ）と上下の回転速度・縦の加速度（長さの伸び縮み）を加えた |
| V9 | 撮影が極端に遅い・止まる（1 コマ 10 秒） | ベクター立ち絵の Canvas 2D をソフトウェア描画にした（GPU エミュレーション上のクリップが遅い）。撮影ツールにコマ単位・セル単位の再試行を入れた |
| V10 | 腕を胸の前に出しても胴の後ろに描かれる（ちびキャラは奥行きが浅い） | 前後の判定のしきい値を頭の半径の 0.1 倍に下げた |
| V11 | 肘を大きく曲げたとき、または上腕と前腕が別の層（上腕は胴の後ろ、前腕は手前）に分かれたとき、色の帯が多いキャラ（アームカバー）の袖に切れ目・欠けが出る | 色の帯を上腕・前腕ごとに作る（腕全体で 1 本の帯にすると、肘で折り返して重なりが打ち消され、肘の外側が塗られない）。別の層に分かれたときは、各部品に自分の区間の帯と影だけを描く。カメラの方を向いた区間では、帯の境目を楕円の弧にする。帯が 2 色以上で肩から手首まですき間なく並ぶ腕は、帯の下に下地を塗らない（下地の縁が、紺の上に明るい細い弧として出る）。帯は次の帯の下へ少し差し込み、境目にすき間を出さない |
| V12 | BPM 140 のように速い動き（拍ごとに腰を左右へ振る）では、揺れ物の根元の加速度が上限近くまで大きくなり、ツインテールが横へ跳ね上がる | 反応の強さ（`vPhysGain`）は下げず、揺れ物が受ける根元の加速度に上限をかける（URL の `vAccMax`、既定 60000 px/s²）。腰振りでは `vAccMax=8000`。`vPhysGain=0.2` で抑えると、耳・しっぽの慣性まで消えてしまう |
| V13 | 手を腕の線から曲げると（例：腰に手を当てるときの手首の曲げ）、手の部品の手首側の縁が、前腕の端の帯（袖口）を斜めに隠し、袖口が片側だけ太いくさび形に見える | 手の曲げは 0（前腕と一直線）にする。手首の縁が袖口の帯と平行になり、袖口の幅がそろう |
| V14 | 脚は膝のない 1 枚の部品なので、腰を左右に振ると脚が股関節で回り、足先が傾いたり浮いたり横へずれたりする | URL の `vPlant=1`（`src/renderers/vector/plant.ts`）で、足裏を止めたまま脚を腰へ向けて横にせん断し、縦に伸縮させる。全身の伸縮も脚では打ち消すため、足は動かず広がらない |
| V16 | 動きのある 1 枚の絵（頭が傾いている）をそのまま参照にすると、正面の姿でも頭が傾いた部品になり、左右交互の動きで傾きが片側に寄る。左右非対称に見えた耳も、頭の傾きによる見かけだった | 顔の左右対称のずれから頭の傾きを測り、頭（顔・耳・頭の塊）をまっすぐに戻して描く。参照の傾きは、モーションで頭を傾けて再現する |
| V17 | 太い輪郭線で描かれた塊のキャラ（頭と胴が一体、腕・脚・しっぽが同じ色）では、部品の重なりの自動輪郭線が、肩の C 字・胸の弧・股の縦線として出て、参照にない線になる | 外側の輪郭線（`vOuter=1&vLine=16&vOuterColor=<線の色>`）で輪郭を出し、同じ色の部品どうし（胴と腕、頭と腕、脚どうし、しっぽと脚・胴）は `seamlessWith` で線なしにつなぐ。塗りは参照の線の内側の縁に合わせて描く（外側の線は塗りの外へ `vLine × 1.3` 太る） |
| V18 | 長い耳を揺れ物にして拍ごとに跳ねると、耳が顔・腕の上へ折れ重なるほど振れる（ばねの固有振動と、頭の左右の傾きの周期が近い） | ばねを少し硬く（`stiffness` 0.62、`damping` 0.4）し、根元の加速度に上限をかける（`vAccMax=6000`）。慣性で遅れて振れる動きは残す |
| V19 | 参照画像に線のない、同じ色の部品の重なり（前髪の下の縁が横髪に重なる所など）に線が出る。`seamlessWith` で 2 部品の線をまとめて消すと、ほかの場所の必要な線まで消える | 線を消したい区間だけを、同じ色で `outline: false` の小さな覆いの部品（例：`hair_cover`。手前の部品の直後に置く）で覆う |
| V20 | Codex の image_gen は参照画像が最大 5 枚。シートの生成で、原画 2 枚＋正面の立ち姿＋H3 のコマ 3 枚（＝6 枚）を渡すとエラーになり、画像が作られない | シートは `--no-angles`（H3 のコマを付けない）で作る。毛の多いキャラ 以外の 3 体も同じ方法で作っている。H3 の回転動画は Fable の参照（立体の形の手がかり）として使う |
| V21 | 縦ロールのように段が重なる揺れ物（`layer: "ear"`）では、首振り中に 2 つめ以降の shape（縞・巻きの内側）が最初の shape で切り抜かれる。最初の shape が一部の段だけだと、ほかの段の縞が消える | 揺れ物・耳の部品は、最初の shape を部品全体の外形にする。縞が向いた方へずれて見える場合は `headTurn.earInner` を下げる |
| V22 | 原画が、色付きの丸い背景・キャプション・小物（電球、盾など）つきのアイコン集だと、画素の処理（彩度での背景除去、輪郭線の内側の塗りつぶし）では、小物の黒い線がキャラの線とつながり、胴の下端が背景の白に溶けていて、きれいに切り出せない | 小物のないコマだけを画素で切り出し、残りは `make.py gen <id> clean`（Codex imagegen）で、同じ並び・同じ絵柄のまま背景・文字・小物を消して描き直させる。小物に隠れた手・胴は補って描かれる |
| V23 | 黒い太線がキャラクター性の中心のキャラでも、`restyle` では共通の画風（同系色の細い線）が勝ち、灰色の線になる | キャラの補足に「黒の太線を残す」と書いたうえで、`--note` で線の色と太さを重ねて指定する。部品は塗りだけで描き、線は V17 の外側の輪郭線で出す |
| V24 | Codex の使用量の上限中に、MiniMax H3 の静止画生成（R2I、`tools/h3/r2i.py`）でシートを作ると、配置の参考に渡した前のシートの体のデザイン（線・色）まで写す。参照なしでも、ミトン型の手を 4 本指の手で描く | H3 には採用済みの立ち姿だけを渡し、配置は文章で指定する。体の図は H3、手は既存のシートの手を合成するなど、うまくできた部分だけを使う。1 枚 33〜63 秒 |
| V25 | 太い黒線（`vOuter`）で全身を囲むキャラでは、線が部品の内側に引かれるため、手前の部品の縁が線の太さの分だけ削れる（頭の下端の線が細く、角で途切れる）。脇の線を消そうと胴と腕を `seamlessWith` にすると、気をつけで腕が胴に溶ける。覆いの部品で線を隠すと、覆いの縁の隙間に 1px の線が残る | 頭に `halo: true` を付け、頭自身の外側の輪郭線で下端の線を出す（首を傾けても角が崩れない）。首振りで頭の外形は動かさない（`parallax.head: 0`）。胴と腕は `seamlessWith` にせず、腕の `rootGap` で肩の点のまわりだけ線を出さない（覆いの部品や胴の切り欠きは使わない）。腕は全部品の裏に描く。線の既定値はキャラ設定の `urlDefaults` に書く（手描き線は `vHand=0`）。描画側は、重なりが線の太さに満たないところ・腕の付け根の丸には線を出さず、手が頭にかからない前の腕は頭の後ろに描く |
| V26 | H3 の回転動画で、体の手前にしっぽが重なる・お尻の横に付いて見える（仮うさぎに続き 2 例目） | しっぽなど体から突き出る部品は、H3 の見本ではなくキャラクターシートの側面図の位置に置き、ずらした量を `coverage` に書く。依頼文に明記する |
| V27 | 見えない部品（奥の横髪 `hair_side_R` など）を鍵ごとに別の場所へ隠すと、中割りで顔の肌の上を横切る（斜めがけのかばんのキャラで 63°〜78° に額の上を赤い楕円が横切った） | 見えない部品は、隣の鍵の置き場所との間を直線で動いても肌の上を通らない場所（前髪の裏など、どの鍵でも同じ側）に置く |
| V28 | 体の斜めがけのストラップなど左右非対称な部品があると、反転した体との中割りで交差する（15°〜22.5° で胸の上に黒いかたまり） | 反対向きの体 `body<角度>_opp.json` を描く（`docs/vector-parts.md` §8.8） |
| V29 | 縦ロール・大きな耳が後頭部につながるキャラでは、60° の体の `headOffset` を行ごとの頭の中央から測れない | 顔の向く側の端を測り、頭の幅は正面の `head_radius` を使う。目測の場合は誤差を報告させる |
| V30 | 太い黒線（`vOuter`）のキャラで、腕が胴に重なる縁の線が、外側の輪郭線より細い灰色で腕の内側に引かれ、外の線とずれてつながらない（カメラを向いた前腕の先が浮いた「C」になる）。前腕だけが胴の前に出ると、肘の丸い端が腹の上に浮き、上腕の付け根に胴の線の切れ端が残る | `urlDefaults` に `vInner=outer`（重なりの線を外側の輪郭線と同じ色・太さで前の部品の外側に引き、外の線とつなぐ）、`vRootGap=1.1`（肩の点から肩幅 × 1.1 の中は腕の線も胴の線も引かない）、`vArmJoin=-0.3`（前腕が胸の前に出たら、肘が胸より頭の半径 × 0.3 以上奥でない限り上腕も前に出して 1 本の腕で描く）を書く。既定はどれも切 |
