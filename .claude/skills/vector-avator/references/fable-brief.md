あなたは vector-avator リポジトリ（リポジトリのルートが作業ディレクトリ）で、キャラクター「{{NAME}}」（キャラ ID `{{ID}}`）の 2D アニメーション用の部品を、ベクター（ベジェ曲線）で描き起こす担当です。
描いた部品は、ベクター立ち絵のレンダラー（`src/renderers/vector/`）が読み込み、3D の骨格の動きに合わせて動かします。腕は描画時にプログラムで生成し、輪郭線も描画時に自動で引きます。あなたは、それ以外の部品の「塗りの形」を、隠れる部分まで補完して描きます。

1. `.claude/skills/vector-avator/references/parts-spec.md` — **仕様（最優先）**。ファイル形式（`vector.json`）、座標、部品の一覧と命名、補完のルール、検査方法。
2. 参照画像（`public/characters/{{ID}}/vector/ref/`）
   - `front.png`（1024×1536）— **主な参照**。この絵と同じ座標・大きさで正面の部品を描く。
   - `sheet_turnaround.png` — 4 面図（正面・斜め・側面・背面）と手の形 4 種。隠れる部分（背中側、しっぽの付け根、耳の根元）の形の手がかり。
   - `sheet_face.png` — 顔の差分（目：開・半目・閉じ、口：閉・あ・い・う・え・お、表情：通常・笑顔・驚き・困り）。
   - `angle_*.png`・`turntable.mp4`（ある場合）— 360 度回転動画。立体の形の手がかり（画風は参考にしない）。
3. 見本：`public/characters/usagi/vector/vector.json`（仮うさぎ。補完の水準・親子・支点・骨格の目印・腕・揺れ物・`qa` の書き方の参考。座標は流用しない）。
4. 描き方の作法：`.claude/skills/vector-avator/references/drawing-workflow.md`、`visual-qa.md`、`art-json.md`（`vector.json` は `art.json` の上位互換）。確認画面の見本は `.claude/skills/vector-avator/assets/example-guide.png`。`assets/mini-character.json` は線あり・大文字の部品名の古い形式の作例なので、補完の考え方だけを参考にし、形式は仕様に従う。

## 守ること

- 部品は意味の単位で**ゼロから描く**。元画像の画素の切り抜き、`<image>`、マスク、自動トレース、色分類・投げ縄・可視輪郭の当てはめで部品の形を決めない。画像処理は、色の抽出、寸法・座標の測定、拡大、重ねての比較に限る。
- **塗りだけで描く**（`stroke: null`、`width: 0`）。参照画像の細い境界線は描かない（レンダラーが自動で引く）。境界線の位置は、隣り合う塗りの境目として表す。眉・閉じた目・口の線などは細い閉じた塗りの形にする。
- **隠れる部分も補完する**。前髪の下の額、耳・髪の付け根の下の頭、腕を外した胴（脇の下まで）、首、しっぽの付け根、スカートの下の脚の付け根など（仕様 §5）。
- 腕（肩〜手首）の部品は**描かない**。代わりに `skeleton` の肩・肘・手首と、`arms` の太さ・色の帯・影を、`front.png` を測って書く。手は差分部品 4 種×左右を、仕様どおり手首から真下に向けて描く。
- 左右の `_L`・`_R` は**キャラ自身の左右**（正面図で `_L` は画面の右）。
- 参照画像の座標は、目測ではなく画素を走査して測る（目・耳の位置は 15〜25px ずれやすい）。
- 1 部品・1 shape が複雑になりすぎないようにする（1 shape 80 区間以下を目安。毛の房は大きな塊にまとめる）。
- 作画は Python などのスクリプト（`var/vector/{{ID}}/fable/draw.py`）で行い、`vector.json` はスクリプトから書き出す。直すときはスクリプトを書き換えて再実行する。

## 検査（納品前に必ず行う）

1. `.venv/bin/python tools/vector/check_parts.py {{ID}}` がエラー 0 件になるまで直す。
2. `var/vector/{{ID}}/check/` の画像を**目で見て**確かめる。
   - `neutral.png` と `ref/front.png` を並べ、半透明で重ねた比較画像を自分で作り（`var/vector/{{ID}}/fable/compare_front.png`）、形・色・頭身・位置が合っているか。
   - `qa_*.png`（手前の部品を隠した状態、部品を動かした状態）に穴・切り口・隙間がないか。
   - `variants.png`（目・眉・口・手・袖）と `expressions.png` が `sheet_face.png`・`sheet_turnaround.png` と合っているか。半目で虹彩が潰れていないか。
   - `skeleton.png` の関節の位置が絵と合っているか。
3. 開発サーバー（`{{VIEWER_URL}}`）が動いている場合は、**実際のレンダラーで**、自動輪郭線と生成した腕を含めた見え方を確かめる（仕様 §6 のコマンドに `VIEWER_URL={{VIEWER_URL}}` を付ける。`var/vector/{{ID}}/check/viewer/` に出力）。白いキャラは、ここでしか境目の見え方が分からない。動いていない場合は、依頼した側にそう報告する。
4. 直したら 1. に戻る。
