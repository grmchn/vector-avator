# 描画の判断：何をどこまで補完するか

ベクター立ち絵の部品分けで、Fable 5.2 が従う作法です。仕様（命名・形式）は `parts-spec.md` が優先します。ベクター立ち絵では線を描かない（塗りだけ）ため、下の「輪郭線と塗りを分ける場面」は、塗りの閉曲線の作り方として読みます。

## 画素の抽出から発想しない

悪い起点：「この色の画素を全部集めれば髪になる」→髪と服の同色が混ざる、アンチエイリアスの縁が残る、隠れた根元は永久に存在しない。

よい起点：「この髪束はこの支点から伸び、この前髪の後ろを通り、この輪郭で毛先まで続く」→可視部を合わせ、隠れた接続を含む閉曲線を描く。

PNGを拡大・採色・位置測定するのは正常な作業。ピクセルを直接運ぶのが今回の目的ではない。細部が読めなければ、まず大きな形と顔の特徴を描き、必要な箇所だけ拡大する。

## 観察を座標へ落とす

元画像の縦横比を維持した共通キャンバスを決める。頭頂、顎、目の中心、肩、腰、足先、髪の付け根を画面座標で記録する。線幅の基準と小さな色パレットを作る。瞳のハイライトのような目印も観察する。

曲線は `M` で始点、`C` で三次ベジェ、`Q` で二次ベジェ、`L` で意図した角、`Z` で閉じる。楕円は4本の三次ベジェで表せる。平坦な輪郭に数十点を置くより、2〜4本の曲線のハンドルを合わせる。数値が分からないまま何百個も点を出さず、少数パスをレンダリングして参照との差を直す。

## 部品表の書き方

例（架空キャラ。数値をそのまま流用しない）：

| 部品 | 隠す部品 | 見えない部分として描く形 | 支点・確認する動き |
|---|---|---|---|
| 顔 | 前髪・横髪 | 額〜こめかみ〜頬まで続く頭の輪郭 | 前髪を左右に少し移動しても額が抜けない |
| 後ろ髪 | 頭・上着 | 頭の内側まで届く根元と後頭部 | 根元から±10〜15°の平面回転 |
| 腕 | 胴体・袖口 | 袖内まで続く丸みのある肩・腕 | 肩から±10°、腕だけを外した一覧でも形が完結 |
| 脚 | スカート | 腰に向かって伸びた上腿 | スカートを上げたりずらしても透明な空洞が出ない |
| 胴体・服 | 腕・襟・ネクタイ | 脇・肩・胸元の連続した面 | ネクタイをずらしても胸が欠けない |
| ネクタイ | 襟・結び目 | 結び目の下へ差し込む上端 | 上端から小さく回転しても切れ目が出ない |

同じ色でも別々に動く部品は分ける。ベクター立ち絵では腕は描かず生成するので、腕の行は胴・袖の補完の考え方として読む。別の色でも一緒に動く部品の模様なら、同一レイヤーの複数パスでよい。片腕が胴体の前と後ろを横切る場合は、前側／後ろ側に描画片を分けて同じ親につなぐなど、遮蔽順を設計する。

## 補完の具体手順

1. 見えている輪郭の両端で、進む方向と太さを読む。
2. 遮蔽物の下へその接線を延長する。断面の幅が突然ゼロにならないようにする。
3. 身体構造・デザインから妥当な全体形を閉じる。可視輪郭はなるべく変えない。
4. 補完部の塗り・模様も連続させる。肌色で塗った長方形を置くだけにしない。
5. 遮蔽物を戻して通常表示に余分な線が出ないことを確認する。
6. 遮蔽物を外す／対象を支点から動かす。隙間が出るなら不足している区間を広げる。

補完余白の目安は「その境界で生じる相対移動＋線幅・アンチエイリアスの余裕」。支点から距離rの点を角度θ動かす変位は `2*r*sin(|θ|/2)`。平行移動もあれば加味する。これは余白を考える手掛かりであり、すべての部品を一律に膨らませる規則ではない。付け根は隠れた受け側を広げ、毛先のような外輪郭はそのままにする。

小さな正面揺れに足りる補完と、腕を大きく上げる・頭を横向きにする補完は別。単一の平面画から裏側まで正しいと断言しない。

## 輪郭線と塗りを分ける場面

肩の塗り面は胴体の下まで閉じるが、その閉じ線を全部黒で描く必要はない。塗り用の閉パスと、見える外側だけの開いた線パスを分ける。逆に一周の輪郭が必要な髪束では、内部の白い模様が外輪郭を上書きしないように最後に外輪郭線を描く。

白は透明ではない。顔の白・白目・服の白など、必要な白い面は独立したベクター塗りにする。穴を背景色で隠すための白いパッチとは区別する。

付属変換器は塗りの穴、マスク、グラデーションには対応しない。必要なら共通原画を適切な閉領域へ分割するか、両形式の実装を拡張し検証する。黙って平坦化して似ていない絵にしない。

## 顔の分離

左右の目は別。白目、虹彩、瞳孔、ハイライトが同じ動きをするなら同一パーツ内の複数パスでよい。眉・まつ毛は前髪との遮蔽と後の動作次第で分離する。

閉眼差分を表示するときは、対応する開眼と前面のまつ毛を隠す。開いた口を表示するときは閉じた口を隠す。顔の土台に開眼や閉口を描き込まない。

## 失敗からの戻り方

| 観察した問題 | 戻って直すもの |
|---|---|
| 輪郭が毛羽立つ・小さな島が多い | 自動抽出を止め、太い外輪郭を少数のベジェで描く |
| レイヤーを動かすと切り抜きの穴 | 可視領域マスクを捨て、土台と対象の閉曲線を完成させる |
| 頭や服が元絵と別物 | 画像の顔・シルエットの観察とランドマークへ戻る |
| 肩に黒い弧・接合部に二重線 | 隠れた境界のストロークを分離し、描画順を直す |
| まつ毛が前髪に埋まる | そのまつ毛だけ独立レイヤーへ。前髪全体を後ろへ移さない |
